# BizFlow — Smart Business Manager

A modern, responsive business management dashboard built with HTML, CSS, and JavaScript.

BizFlow helps small businesses organize their daily activities by managing tasks, projects, customers, and business information from one dashboard.

## 🚀 Features

### 📊 Dashboard
- Business overview and summary cards
- Total tasks, completed tasks, and pending tasks
- Project and customer statistics
- Task progress tracking
- Recent activity history

### ✅ Task Management
- Add, edit, and delete tasks
- Mark tasks as completed or reopen them
- Set task priorities and due dates
- Search and filter tasks

### 📁 Project Management
- Create and manage projects
- Add client names and deadlines
- Track project status
- Search and filter projects

### 👥 Customer Management
- Add and manage customer records
- Store customer contact information
- Edit and delete customer details
- Search customers

### ⚙️ Business Settings
- Save business name
- Manage business email and phone
- Store business address
- Display saved business information on the dashboard

### 👤 Admin Profile
- Interactive admin dropdown
- Smooth dropdown animation
- Demo sign-out option

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage

## 💻 Getting Started

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or your browser.
4. Start managing your business information.

## 💾 Data Storage

BizFlow currently uses browser LocalStorage to save tasks, projects, customers, business settings, and recent activity.

Data is stored locally in the browser and is not synchronized across devices.

## 🔐 Current Limitations

- No backend database yet.
- No real user authentication.
- Admin sign-out is currently a demonstration feature.
- Data is stored locally in the browser.
